# 🎓 CareerAI

### Smart Student Career Assistant

CareerAI is an AI-inspired career exploration platform designed to help students discover technology career paths based on their **skills, interests, and courses**.

## 🚀 Live Demo

👉 **https://careerai-lkzmedfb7ytaybh9fddsmd.streamlit.app/**

## ✨ Features

- 🎯 Career Analyzer
- 📚 Course-based Career Explorer
- 💻 Skill matching
- ❤️ Interest-based matching
- 📊 Career match percentage
- 📚 Skill gap identification
- 🛣️ Learning roadmaps
- 🔎 Career search
- 🎨 Modern Navy + Teal interface

## 🧠 How It Works

**Profile → Skills → Interest → Career Matching → Skill Gap → Learning Roadmap**

CareerAI compares the student's selected skills and interests with available career paths and provides relevant career information.
